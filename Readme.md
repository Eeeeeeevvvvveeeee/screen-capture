# Screen Capturer

A minimal Electron desktop app for capturing screenshots. Features a frameless window with custom controls and system tray integration.

## Features
- 📸 One-click screen capture
- 🪟 Frameless, transparent window
- 🎛️ Custom window controls (minimize / maximize / close)
- 📌 System tray integration
- 💾 Saves screenshots to your home folder

## Prerequisites
- [Node.js](https://nodejs.org/) (v16 or higher)
- npm (comes with Node.js)

## Installation
\`\`\`bash
git clone https://github.com/Eeeeeeevvvvveeeee/screen-capture.git
cd screen-capturer
npm install
npm start
\`\`\`
